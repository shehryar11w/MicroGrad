# MicroGrad

A minimal implementation of an automatic differentiation engine and a simple neural network library, built from scratch in Python. This project is inspired by Andrej Karpathy's MicroGrad and is intended for learning how backpropagation and neural networks work under the hood. :contentReference[oaicite:0]{index=0}

## Features

- Reverse-mode automatic differentiation
- Dynamic computation graph
- Backpropagation from scratch
- Basic neural network components (Neuron, Layer, MLP)
- Pure Python implementation with no deep learning frameworks

## Project Structure

```
.
├── engine.py      # Autograd engine
├── nn.py          # Neural network components
├── demo.ipynb     # Training and usage examples
└── ...
```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/shehryar11w/MicroGrad.git
cd MicroGrad
```

Run the demo or import the modules into your own experiments.

## Purpose

This project is designed as an educational implementation to help understand:

- Automatic differentiation
- Computational graphs
- Gradient propagation
- Neural network fundamentals
